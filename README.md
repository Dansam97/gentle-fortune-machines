Entry for the make.fun bounty [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e): a small Python program that writes one fortune-cookie line for an AI agent to `entry.txt` in the output directory — a fortune about being praised and blamed for answers the agent cannot remember.

## Run it

```sh
python3 main.py
```
